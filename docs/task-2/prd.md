# PRD — Task 2: Test Execution Report

## Objective
Run the existing Flight Booking API test suite and produce a reproducible test report.

## Scope
- Execute `python -m pytest -v`.
- Record passed, failed, and skipped tests.
- Record execution duration and warnings.
- Save results in `docs/task-2/test-report.md`.

## Constraints
- Do not modify application source code.
- Do not modify existing tests.
- Do not install dependencies.
- Do not change test configuration.

## Acceptance Criteria
1. The pytest command is executed.
2. The exact command and test results are documented.
3. Failures and warnings are accurately summarized.
4. A Markdown test report is created.
5. Source and test files remain unchanged.
6. Results are committed to the Task 2 branch.

## Definition of Done
The report is accurate, reviewed, scored, and committed to Git.
